
# NuGet Packages

Кроссплатформенное приложение на Flutter (Android, iOS, Desktop, Web) для обзора, поиска и исследования каталога .NET / NuGet пакетов, версий и зависимостей. (Основано на проекте DotNetPackages).

## Предметная область
Приложение решает задачу удобной навигации по библиотекам .NET:
- Просмотр каталога популярных .NET пакетов.
- Поиск по названию пакета и описанию.
- Экран «Ничего не найдено» с возможностью быстрого сброса поиска.
- Детальная страница пакета: текущие версии и список зависимых библиотек с возможностью перехода по графу зависимостей.

## Архитектура и стек технологий
- **Фреймворк:** Flutter (Dart) для обеспечения единой кодовой базы как для UI, так и для бизнес-логики на всех платформах.
- **Навигация:** Встроенный Flutter `Navigator` для перехода между экранами (роутинг с передачей аргументов).
- **State & Data Handling:** Управление состоянием через `StatefulWidget` с типизированными состояниями `UiState` (Loading, Success, Error).
- **Repository Pattern:** Использование `MockPackageRepository` с локальными моками для получения списков и деталей пакетов (с имитацией задержки сети).

## Команды запуска

### Подготовка проекта
- Скачивание зависимостей и генерация платформенных папок:
  ```bash
  flutter pub get
  flutter create .
  ```

### Mobile (Android / iOS)
- Запуск на подключенном эмуляторе или реальном устройстве:
  ```bash
  flutter run
  ```

### Desktop (macOS / Windows / Linux)
- Включение поддержки десктопа (если не включено):
  ```bash
  flutter config --enable-macos-desktop
  ```
- Запуск десктопного приложения:
  ```bash
  flutter run -d macos
  ```
  *(Для запуска macOS-версии требуется установленный Xcode)*

### Web
- Запуск веб-версии в браузере (Chrome):
  ```bash
  flutter run -d chrome
  ```
