## Proposed Changes

### 1. Git и структура веток
Необходимо избавиться от "грязной" истории (папок `build/`, `.dart_tool/` весом 390МБ).
- Переключение на чистую ветку `main`.
- Создание ветки `develop` от `main`.
- Создание рабочей ветки `feature/lab-2_frame` от `develop`.
- Установка стандартного Flutter `.gitignore`.

### 2. Зависимости (pubspec.yaml)
- Добавление `flutter_bloc` и `equatable` для State Management.
- Добавление `go_router` для навигации.
- Добавление `flutter_localizations` и `intl` для поддержки двух языков (ARB).

### 3. Локализация (l10n)
- Создание `l10n.yaml`
- Создание `lib/l10n/app_ru.arb` и `lib/l10n/app_en.arb`.

### 4. Рефакторинг архитектуры (features/package/...)
Создание структуры Clean Architecture:
- `lib/features/package/domain/`: Сущности (Models).
- `lib/features/package/data/`: Репозиторий (MockPackageRepository).
- `lib/features/package/presentation/`:
  - `bloc/`: Cubit для списка, Cubit для деталей, Cubit для темы.
  - `pages/`: Экраны списка и деталей.
  - `widgets/`: Переиспользуемые виджеты.

### 5. Логика (Cubit & GoRouter)
- Замена `setState` на `PackageListCubit` и `PackageDetailCubit`.
- Реализация `ThemeCubit` для переключения светлой/темной темы.
- Настройка `GoRouter` (переход на детали по пути `/package/:id`).

### 6. Атомарные коммиты
- В процессе выполнения код будет коммититься частями с префиксами `chore:`, `feat:`, `refactor:`, как требует преподаватель.
